Mode: Operate. A calm analytical workspace for reading and navigating conversations.

Near-white surfaces, pale cool sidebar, navy text, cobalt primary actions, muted semantic sentiment colors with text labels. Clean sans serif, tabular numerical data, fine separators and modest radii. Sidebar conversation search, compact header and date controls, inline metrics, large readable visualizations, moment list and linked message reader. Admin uses the same visual language and exposes connection status, chat access management and persistent job progress.

Responsive: sidebar becomes a dismissible navigation drawer, charts keep meaningful labels and tables scroll within their own container. No content is available before server authorization. Include loading, empty, locked, error and unconfigured states, visible focus, touch-friendly targets and reduced motion.

November 2026 refinement: sidebar contains conversation search/list at full height and a single Amministrazione destination. Global period controls use custom calendars and quick ranges. Overview has no selectable moment. Moments use tone chips and participant-colored Telegram-like bubbles. Statistics chips select a single visible section; media comparison uses grouped bars and longest-message lists contain ten entries. Profile/chat images, owner identity and participant colors are configurable in admin. All interface icons use Font Awesome.

Privacy refinement: the entry route and logo open a neutral home. No anonymous conversation metadata is listed. Guests discover only chats matching a valid password; admin sees all. No taglines/footer copy. Admin sections use tabs and chat settings use an overlay with focus management. The period control is a single range calendar. Both rhythm and analyzed tone charts remain visible. Moment cards have a date/time header, tone and count at right, and the reader summary on the second row. Markdown is rendered safely with remote images disabled.

Context refinement: chat editing orders full-width type, image/name, owner and colors. Removal is confirmed in a dialog. Relationship duration joins the overview metrics. Moment descriptions contain factual context only when analyzed; reply bubbles quote available originals. Poemi uses uniform full-text cards under All/participant tabs. Statistics category chips have no lower divider and tighter spacing.

Archive refinement: admin home contains archive totals, recent conversations and processing status; public home stays private. Desktop navigation can collapse to an avatar/icon rail, retaining accessible names. Images share Add/Change and bordered red remove controls. Owner identity uses explicit radio choices and persistent save feedback. Telegram/AI status copy is minimal; segmentation is server configuration. Import uses an overlay. Search lives in Moments; the separate Messages view is removed. Poemi keeps All/participant tabs and individual collapsible messages.

Control refinement: the sidebar toggle is a directional chevron; in the compact rail it sits above the smaller brand mark, at the top right. Image actions are real buttons with pointer and hover states. Owner radios have explicit 16px sizing. Chat Save stays visible and is disabled without unsaved changes; analysis queue acceptance produces a dismissible success toast. Telegram and AI share Connessioni. Search uses amber inline highlights in context, Markdown text and reply previews. Poemi includes its explanatory caption.

Final layout refinement: compact navigation reduces the gap below the brand; the labeled collapse action moves above the administration divider, becoming icon-only in the rail. Telegram and AI use matching icon/status/subtitle rows. Chat image and name form a left column beside vertically stacked owner choices with matching labels. Import is a searchable list with useful Telegram metadata and persistent selection across filters.

Analysis planner: the conversation table exposes a dedicated Analisi icon beside Gestisci, Aggiorna and Elimina. Analysis opens its own focused dialog; chat settings no longer contain an inline estimate. A styled keyboard-accessible range slider drives cumulative input/output totals and the oldest selected timestamp. Queue submission confirms success; empty/error/unconfigured states are explicit.

Access and moment refinement: admin credentials never share state with guest unlock. Conversation rows include accessible analysis progress. Tone chips show full filtered counts without a pending chip; a custom select orders moments by newest, oldest or message volume. Owner and participant names are resolved before display, including quotes.

Conversation export: an icon-only download action above the moment reader exports only the selected moment. Moments search and ordering share one row on desktop and mobile.
